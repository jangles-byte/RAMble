# Filigree

*Design philosophy for the Filigree scene — a Clifford strange attractor as
"the shape of the machine's mind." Built on the Atelier generative-motion
system reference; base seed (−1.4, 1.6, 1.0, 0.7), animated by orbiting the
seed, never by traveling between seeds.*

**The job:** show the machine's state as a single evolving *form* — one
object you recognize from across the room, whose posture and heat say how
hard the system is working.

Filigree believes computation has a shape. One deterministic orbit, iterated
thousands of times a frame, deposits a filament sculpture out of faint
overlapping points — structure built from patience, not brightness. The
sculpture is never finished: its parameters breathe in slow orbits around
the seed, so the form flexes like something alive under glass.

Load is tempo. CPU and stress quicken the parameter orbit, so an idle
machine holds an almost-still form and a busy one visibly kneads and folds
it. Memory sets density — more RAM in use, more iterations, a heavier lace.

Color is earned by velocity, exactly as the system reference prescribes:
slow regions of the orbit stay ash-silver, fast sweeps heat into the theme's
palette. Token generation pours heat in — while a model streams, the newest
points burn bright and colored before cooling into the lace. Stress warms
the whole ramp; swap stains it red. A model load re-seeds the attractor
entirely: a new mind, a new shape.

**Is not:** a screensaver rainbow, a particle explosion, or symmetric.
Kills on sight: hue cycling over time, uniform density, parameter jumps
that empty the orbit.
**Signature move:** one continuous chaotic filament sculpture that kneads
itself faster the harder the machine thinks — and re-forms into a different
sculpture each time a model loads.
