# Mycelium

*Design philosophy for the Mycelium scene — Physarum slime mould as the
machine's hunger. Built on the Atelier generative-motion system reference:
agents deposit trail, sense ahead, steer toward what they sense; the
feedback builds transport networks that look alive.*

**The job:** show the machine as an organism foraging — a living network
that thickens where the system feeds and starves back to filaments when
pressure bites.

Mycelium believes intelligence is search. Thousands of blind agents, each
following a three-sensor rule, together grow a fungal freeway system — no
plan, all emergence. The colony seeds as a ring and grows outward, so every
run has a birth, and the network the viewer watches is genuinely being
found, not replayed.

Decay is the drama, exactly as the system reference says: it is the whole
piece. A calm machine holds a dense, confident lace; stress lowers the
trail's half-life so the web thins to nervous filaments — the network
*starves* under pressure and re-thickens in relief. Speed follows CPU: a
busy machine forages faster.

Color is earned by concentration. Lone scouts are ash-silver; where the
colony agrees — the trunk routes, the busy junctions — the trail heats into
the theme's palette. Tokens are food: while a model streams, fed agents burn
bright with color and deposit double, so inference visibly redraws the
network's highways. Swap stains the whole organism toward red.

**Is not:** static lace, uniform mesh, or instant. Kills on sight: seeding
agents uniformly (the boring even web), rainbow trails, decay so high the
screen fills to a grey mat.
**Signature move:** the network is never finished — it starves thin under
pressure and regrows dense in calm, a living map of the machine's appetite.
